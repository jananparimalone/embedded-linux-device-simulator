A simulated Linux platform project demonstrating:

- Linux system services
- Docker containerization
- Jenkins CI/CD
- Python automation
- Monitoring and recovery scripts
- Security hardening concepts
- Embedded systems engineering workflows

Technologies used include:

- Ubuntu Linux
- Python
- Docker
- Jenkins
- systemd
- Bash
- Github

NOTE: Should be run on Ubuntu OS with all technologies listed installed 

Commands to run & monitor:
systemctl status device.service
docker run device-sim
journalctl -u device.service -f
